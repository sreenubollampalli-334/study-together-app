## 🚀 Overview

Study Together is a full-stack collaborative learning platform designed to help students connect, learn, and grow together through peer-to-peer knowledge sharing and structured learning experiences.

The platform enables students to discover study partners based on skills and learning interests, join collaborative study rooms, participate in discussions, share learning resources, manage study schedules, and track learning progress through gamified engagement features.

Built using modern full-stack technologies, Study Together demonstrates secure authentication, scalable RESTful API development, real-time collaboration workflows, community management, and responsive user experience design.
